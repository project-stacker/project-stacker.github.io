# Software Provenance Workflow Using SBOMs as OCI Artifacts

!!! info
    This functionality has been removed.

    Stacker up to v1.1.6 included support for creating a Software Bill of Materials (SBOM) during container build as a related OCI artifact, using a built-in scanning command based on the library at github.com/kubernetes-sigs/bom - however this compiled-in integration made keeping stacker and the stacker lib free of CVEs difficult, and has been removed. Track https://github.com/project-stacker/stacker/issues/755 for discussion of reenabling this feature.
